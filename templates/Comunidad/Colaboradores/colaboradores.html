Colaboradores

Los proyectos de SXcontrol pueden crecer con ideas, revisiones y contribuciones de la comunidad.

¿Cómo participar?

Por ahora, esta página no publica una lista de colaboradores. Para evitar atribuir contribuciones incorrectamente, aquí compartimos formas de participar en los repositorios públicos:

1. Explora el código

Revisa los repositorios y sus instrucciones para conocer el estado del proyecto antes de proponer un cambio.

Ver repositorios

2. Propón una mejora

Usa la sección de Issues del repositorio correspondiente para describir errores, ideas o documentación que haga falta.

Issues de SXcontrol

3. Envía una contribución

Cuando haya cambios listos, puedes proponerlos mediante un Pull Request para que sean revisados.

Pull Requests
